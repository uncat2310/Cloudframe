# 设置说明

[English](settings.en.md) · 简体中文

Cloudframe 的「上传」「画廊」设置保存在各自的浏览器里，换一台设备需要重新设置。存储桶、公开地址和登录密码在服务器端配置，见[部署指南](../selfhost/README.md)。

<a id="upload-settings"></a>

## 上传设置

### 图像转换和压缩

在上传之前转换或压缩图片，默认关闭（图片按原样上传）。

| 选项     | 说明                                                                  |
| -------- | --------------------------------------------------------------------- |
| 目标格式 | `WebP`、`AVIF`、`JPEG` 或 `PNG`。转换后文件扩展名会随之改变           |
| 质量     | 1 到 100 的整数，越大越清晰、文件越大。`PNG` 是无损格式，没有这个选项 |

压缩在浏览器里完成，不经过服务器。上传列表里可以对单张图片「重新压缩」，或先「编辑」再上传。

> 上传特别大的图片偶尔失败时，开启压缩通常就能解决（Workers 免费版每次请求的 CPU 时间有限）。

<a id="key-template"></a>

## 键（名称）模板

模板决定图片上传到存储桶后的路径和文件名，也就是图片链接里域名后面的那一段。默认模板是：

```
i/{{year}}/{{month}}/{{day}}/{{ulid-dayslice}}.{{ext}}
```

上传 `photo.jpg` 时，会得到类似 `i/2026/10/20/bzrxwg-gabb.jpg` 的名称。

### 可用的占位符

| 占位符              | 替换为                                                       | 示例            |
| ------------------- | ------------------------------------------------------------ | --------------- |
| `{{year}}`          | 上传时的年份（4 位）                                         | `2026`          |
| `{{month}}`         | 月份（2 位）                                                 | `10`            |
| `{{day}}`           | 日期（2 位）                                                 | `20`            |
| `{{timestamp}}`     | Unix 毫秒时间戳                                              | `1792483583079` |
| `{{filename}}`      | 原文件名中第一个 `.` 之前的部分                              | `photo`         |
| `{{ext}}`           | 文件扩展名（不含 `.`，小写）；压缩转换格式后是新格式的扩展名 | `jpg`、`webp`   |
| `{{ulid}}`          | 完整的 ULID，全局唯一、按时间排序                            | `01JAB3...`     |
| `{{ulid-dayslice}}` | ULID 的一段（6 位 + 4 位），同一天内不会重复                 | `bzrxwg-gabb`   |

建议：

- **以 `.{{ext}}` 结尾**，这样文件扩展名和实际格式一致，浏览器能正确显示。
- `{{ulid-dayslice}}` 只在同一天内唯一，要和 `{{year}}/{{month}}/{{day}}` 一起使用；单独使用时请换成 `{{ulid}}`。
- 只用 `{{filename}}` 时，同名文件会互相覆盖，最好再加上时间或 ULID，例如 `{{filename}}-{{timestamp}}.{{ext}}`。
- `{{random}}` 是旧写法，等同于 `{{ulid-dayslice}}`，请改用后者。

### 默认模板和模板预设

- **默认模板**：每次上传默认使用的模板。上传前在列表里点「编辑」，可以只为这一张图片改名称。
- **模板预设**：保存几个常用模板，需要时一键「设为默认」。
- 带「系统」标记的是内置的默认模板（上面那个），一直可选，不能删除。
- 在服务器上设置 `CLOUDFRAME_KEY_TEMPLATE` 后，新打开面板的浏览器会用它作为默认模板。

<a id="gallery-settings"></a>

## 画廊设置

| 选项     | 说明                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 自动刷新 | 默认开启。每次打开画廊都会重新获取文件列表。关闭后使用浏览器里缓存的列表，需要时点画廊上方的「刷新」 |

画廊里还可以：

- **搜索**：按文件名（路径）模糊搜索；搜索时按匹配度排序。
- **筛选**：按路径前缀（像目录一样浏览）或按上传日期筛选。
- **排序**：按日期或名称，升序或降序。
- **批量操作**：全选当前页（快捷键 Ctrl+A）、复制所选链接、批量删除。
- **单张图片**：打开、查看信息、复制链接或 Markdown、下载、重命名、删除。

只想显示某个前缀下的文件时，在服务器上设置 `R2_INCLUDE_PATH`（例如 `i/`），见[部署指南](../selfhost/README.md)。
